Tiny SOL trend bot: EMA(8/21) crossover entries plus CCI dip entries inside an uptrend, with a 24-hour momentum-rank filter, a quick 1% take-profit and an 8% stop. It paper-trades hourly Solana bars and beats buy-and-hold by sitting in cash through downtrends instead of riding them down.

## Run it

```sh
node main.ts
```
